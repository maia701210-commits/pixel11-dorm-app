宿舍巡房 APP V6_03｜Pixel 11 安裝版

這一版以已驗證的 V6_02 為核心，不加入 Google Drive、不加入 Google Cloud、不需要分享連結。

保留：
- 10 個固定宿舍
- 房號／位置自由輸入
- 同一房間可拍／選多張照片
- 原始照片與壓字照片分開保存
- 每個房間獨立
- 完成這間 → 下一間
- 單間 ZIP
- 整次巡房 ZIP
- 巡房紀錄留在本機
- 明確刪除才會刪除巡房資料

新增：
- PWA 安裝資訊
- Pixel 11 桌面安裝
- Service Worker 離線快取
- App 圖示
- portrait 顯示
- 優先要求瀏覽器保留本機儲存

重要：
V6_03 是「可安裝的網頁 App（PWA）」版本。Android Chrome 必須從 HTTPS 網址安裝 PWA；不能直接用 file:// 的 index.html 安裝成獨立 APP。
安裝完成後可直接從 Pixel 11 桌面開啟，並可在沒有網路時使用已快取的 APP。
